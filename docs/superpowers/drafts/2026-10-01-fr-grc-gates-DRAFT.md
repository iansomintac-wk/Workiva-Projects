# FR and GRC graduation gates: DRAFT for Ian and the FR OSMs, 2026-10-01

**Status: draft, not adopted.** The tracker ships Financial Reporting and GRC with **empty** gate lists (ruling R10).
Nothing below goes into the tracker until Ian approves it. Once approved, it goes in through Settings → "Graduation
gates", one gate per line; there is no code change.

**Source.** Every gate is restated from a deliverable in the tracker's own curriculum (`DEFAULT_SESSION_TEMPLATES`
in `osm-book-of-business-tracker-1.0.html`, master `d5b9526`). The session that supplies it is named in brackets. No
Workiva documentation was read, and nothing was looked up outside the repo. Which gates belong to which goal type is
the drafter's judgement, so each list is a proposal.

**What a gate is.** A gate is something the customer has done, not something the OSM showed them. Gates are copied into
a goal when it is created, and the OSM can add, rename or remove them on that account. They inform the graduation
verdict but never block it (R4). The Sustainability lists have 5 / 5 / 3 / 3 gates, so these drafts aim for the same size.

## Financial Reporting

### Publish this cycle's report/filing
1. Source spreadsheet data linked into the filing document [Linking & Data Integrity Setup]
2. XBRL tagging completed and validated [XBRL Tagging Setup]
3. Test filing completed with no critical issues [Document Health & Test Filing; this is the curriculum's TTFV-1 milestone]
4. Certification and sign-off cycle completed [Certifications & Sign-off Workflow]
5. Filing submitted [no session; the counterpart of Sustainability's "Report published or filed"]

### Set up for next cycle
1. Source spreadsheet data linked into the filing document [Linking & Data Integrity Setup]
2. XBRL tagging completed and validated [XBRL Tagging Setup]
3. Next reporting period folder rolled forward with copies of all source files [Roll-Forward Process]
4. Cross-functional reviewers (legal, IR, auditors) given access [Cross-Team Collaboration & Permissions]
5. Roll-forward walked through with the customer [Roll-Forward Process; same wording as the Sustainability gate]

### Program / data only
1. Roles assigned to reporting leads and IT contact [Platform Orientation & Workspace Setup]
2. Source spreadsheet data linked into a document [Linking & Data Integrity Setup]
3. First linked presentation produced from source data [Presentations & Board Reporting]

### Disclosure submission
1. XBRL tagging completed and validated [XBRL Tagging Setup]
2. Test filing completed with no critical issues [Document Health & Test Filing]
3. Submission made [no session]
