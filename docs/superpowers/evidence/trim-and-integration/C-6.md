## How R4 is met

- Today per-account: a Brief my day bar on Today (button only when an AI key or a connector exists). One `brief_my_day`
  request; each open account gets one next action and any drift/risk flags, each with "why: <reason>". Shown on the track
  line, the below-the-day rows, the beat panel and the account's Overview (`renderOverviewTab`). Items with no reason are
  dropped and counted. The deterministic SIGNAL_DEFS ranking is untouched (c6c) and needs no connector.
- Copilot = book read: `renderCopilot` no longer calls `needsAttentionList()` (its "N accounts need attention right now"
  line is gone); `generateCopilotRead`'s lenses now ask for what moved this week (WEEK) and patterns across accounts (NEXT),
  and say one-account next actions belong to Today. `needsAttentionList` itself stays (Today, diff, telemetry).
- Advisory: `ui.dayBrief` is session-only; the probe shows `DATA` byte-identical after a brief and its re-render. No call
  on load or timer (probe: zero requests on render; c6d source guard). Model text escaped (probe: no injected element).
  Truncated -> the existing length-cap wording. No AI -> no bar at all.

## Step 6 smoke against the real fake connector

`node connector/server.mjs` with a temp config (port 0, all fake), temp token and log in the job tmp dir; a seed that saves
connector settings and returns the `briefMyDay()` promise (the harness evaluates seeds with awaitPromise, so it waits for the
real round trip). Result: 16 of 16 open accounts, first entry `{"nextAction":"FAKE next action","reason":"FAKE reason",
"flags":[{"kind":"drift",...,"reason":"FAKE reason"}]}`. Server stopped by PID afterwards.

Finding (root-caused, not fixed here): with `tools/selfcheck.mjs` as is, the request fails ("connector is not reachable").
An origin-logging stub showed the harness Chrome sends `Origin: file://` because of `--allow-file-access-from-files`; the
connector allows only `null` and localhost, so it correctly refuses. B0 showed a normal browser sends `null`. The smoke was
run with a temporary copy of the harness minus that one flag (deleted after). C-7's plan already launches Chrome without it.
