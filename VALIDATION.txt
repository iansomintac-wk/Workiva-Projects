WHAT WAS NOT VERIFIED
---------------------
Served over http://127.0.0.1, not file://. The browser tooling used for this
run refuses file:// URLs, so the suites were run against a local static server
pointed at the bundle folder. This is not the same as the offline file:// path
the bundle is meant to be used from, and it is worth noting for two features in
particular:

  - The guide's compatibility check has a documented http-only branch (the HEAD
    request). From file:// it falls back to comparing hrefs, which is the
    weaker of the two paths and is the one most users will actually hit.
  - Automatic backup depends on the File System Access API, whose availability
    and permission behavior can differ by origin.

Not exercised in this run:
  - Automatic backup end to end. Choosing a file, granting write permission,
    and confirming a written payload all require user gestures and write to
    real disk. The suite asserts the three guards that keep the check suite
    from ever writing a fabricated book to a real backup file, and those
    assertions pass, but no actual backup file was written or restored.
  - Any AI Copilot feature. These call the Anthropic API and need a key.
  - Gainsight CSV import against a real export.
  - Cross-browser behavior. Chrome only.

None of the above was changed by the 1.0 packaging work — the changes were to
file names, the file header comment, version strings, and the bundle
documentation. No application logic was touched.


SCOPE OF THE 1.0 CHANGE

    osm-runway-onboarding-v4.4.html to osm-runway-onboarding-1.0.html.
  - Replaced the tracker's 1,623-line in-file changelog header with a short

    wrote fresh CHANGELOG.txt, VALIDATION.txt, README.txt and
    guide-manifest.json describing 1.0.
  - Left the ~1,300 "vNN" markers in JS comments and self-check labels in
    place. They are provenance pointing into the archive, they are invisible to
    anyone using the app, and rewriting them would have destroyed the reasoning
    behind individual lines for no user-facing gain.
