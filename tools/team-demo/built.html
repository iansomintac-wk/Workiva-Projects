Safety rails

  • 127.0.0.1 only: the connector and this page listen on the loopback address and nothing else.
  • Bearer token: every connector call must carry the token written to a private temp folder.
  • Dry-run by default: sends are previewed and nothing is written until you confirm.
  • Write gate: writes to Gainsight stay off unless the gate is switched on in the connector's config.
  • Sandbox first: the first real writes go to a sandbox tenant, never production.
  • Idempotent item ids: each update carries a stable id, so a retry cannot apply it twice.
  • Offline rule: when the connector is down, the tracker changes nothing.
