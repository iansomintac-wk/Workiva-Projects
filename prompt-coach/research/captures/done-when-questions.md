# Questions list capture

Made-up prompts. Each shows the Strong prompt, then the block under it on the page.

## FR

**Prompt:** Check the Example Co revenue numbers

**Strong prompt:** “Work only from the text, table, or file I have selected. This is for the reader of this report. For the Example Co revenue numbers: list every number or statement that does not match. For each mismatch, give both locations and both values in a table. Do not decide which value is correct.”

To make it even better, tell Workiva AI:

- Which file or section should it read?
- Who is it for?
- How long, and in what format?
- What should it do if the data is missing?
